# Security and privacy

Quiet TV has no Internet permission, analytics, account system, or remote-control server. It queries installed apps to populate its launcher and stores preferences locally. Its optional Sleep accessibility service cannot retrieve window content or filter keys and only requests lock-screen/sleep when the user activates Sleep.

Home on Fire is separate software with its own permissions and security model. Review its upstream documentation independently. Enable ADB only on trusted networks and authorize only computers you trust. Keep signing keys private. Do not paste device identifiers, account information, or unredacted logs into public issues.

For a vulnerability, use GitHub's private vulnerability reporting on the repository's Security tab if enabled. If it is unavailable, ask the maintainer for a private reporting channel without posting exploit details publicly. For ordinary UI issues use the bug report template. This personal project has no guaranteed response-time SLA.

# Third-party assets and dependencies

## Quiet TV materials

The original Java implementation, build scripts, documentation, vector icons and animations, and abstract wallpapers generated by `scripts/generate_wallpapers.py` are offered under the repository's MIT license. The wallpaper generator uses mathematical gradients and silhouettes, not downloaded images or image-generation model output.

## Personal wallpaper collection (excluded)

The author's local development copy contains photographs and character artwork from a personal wallpaper folder. The project does not have a complete author/license/redistribution record for that collection. It is therefore excluded from Git and not part of the open-source asset grant. Public builds generate original replacement backgrounds for those slots.

**A local APK built with private wallpapers still contains those images.** Do not upload that APK as a public release. Build releases from a clean checkout of the public repository, or supply a collection whose redistribution rights you have verified. Screenshots of personal demo wallpapers and app logos are not relicensed by this repository.

## App artwork and trademarks

App banners and icons are read at runtime from apps installed on the user's device. Streaming-service names, logos, Apple/tvOS, Amazon/Fire TV, and other third-party marks belong to their respective owners. The MIT license does not grant rights to those marks. There is no affiliation or endorsement.

## Home on Fire

[Home on Fire](https://github.com/toolicious/home-on-fire) by toolicious is an optional, separately installed helper, licensed upstream under GPL-3.0-or-later. This project does not include its source or binary in the Quiet TV APK, and does not download or install it during a build. Follow its repository for source, licensing, releases, and setup. No helper code was copied into Quiet TV.

## Build tools

JDK, Android SDK and command-line tools, Python, GitHub Actions and runner software are installed separately under their respective licenses. Android framework APIs are referenced at build time; Android platform binaries are not bundled into the source repository. No third-party runtime library is included in the launcher.
